# 個人學術網站

## 怎麼更新內容

到 https://app.pagescms.org 用 GitHub 登入，打開這個專案，就能在後台編輯：

- **個人資料與經歷**：姓名、簡介、學歷、工作經歷、學術服務、獲獎紀錄
- **學術發表**：新增、修改、刪除論文
- **歷年授課**：課程大綱、教學內容、課堂任務、課程評鑑
- **學生成果**：大學部專題、碩博士論文、學生得獎紀錄
- **研究團隊成員**

按下儲存後約 1～2 分鐘，網站會自動更新。

## 檔案說明（一般不需要動）

| 位置 | 用途 |
|---|---|
| `content/` | 網站的所有內容（後台編輯的就是這裡） |
| `media/` | 從後台上傳的照片與 PDF |
| `assets/` | 網站樣式與互動 |
| `build.js` | 把內容組成網站的程式 |
| `.pages.yml` | 後台的欄位設定 |
| `.github/workflows/deploy.yml` | 自動發布設定 |

注意：這個專案是公開的，`content/` 裡的內容（包含沒有勾選「公開顯示」的草稿）任何人都能在 GitHub 上看到。
